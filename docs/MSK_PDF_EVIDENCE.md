# PDF filing evidence

MIT licensed PDFPlumber (https://github.com/jsvine/pdfplumber), pinned at 0.11.10 for offline extraction. Import only; no third-party code copied. Preserve upstream and transitive notices in distributions, audit dependencies before release. Exact identity, scope, period, units, unique rows, explicit column and document digest required. Synthetic PDF test fixture only. Current supported format is an explicitly labeled machine-generated table, not an assertion that any live NSE issuer uses this layout. Operator must verify source authenticity, filing/revision timing, match to secondary and exchange metadata, commercial data rights, and approve independently. This extractor never publishes or upgrades staging. No OCR, no YTD guessing, no live dependency or deployment.
