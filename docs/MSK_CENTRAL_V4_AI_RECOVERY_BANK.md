# AI missing data recovery bank

Each pilot emits msk_ai_missing_data.json and retains it as a GitHub Actions
artifact for seven days. Missing or conflicting observations remain withheld.
Other stocks remain independently usable as candidates if their own gates pass.
The stage result is still honest; an incomplete run is not reclassified as
fully verified. Financial secondary candidates and partial filing matches are
queued for independent field verification. Recovered DMart history is not
queued if its current technical gates pass.

Use this file to request original public source leads through the existing
AI recovery module or an approved manual AI research task. Never accept AI
numbers. Preserve issuer identity, exact period, scope, unit, source URL and
independent verification before closing a task. Existing pilot artifacts are
snapshots; durable cross-run deduplication, automated AI execution and
persistent resolution receipts remain future work. No paid API or production
changes. Next scale stages: 100, 250, 500. Do not silently exclude a failed
stock from the original denominator. A partial coverage run may continue
research on successful stocks while unresolved items remain in the bank.
