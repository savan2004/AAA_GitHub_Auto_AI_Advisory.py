# Premium Portfolio Builder report

Three pages: capital dashboard with donut, full stock allocation with Indian grouping, and compact industry exposure plus source hyperlinks. A fourth historical risk page is required only when approved adjusted returns are used by the optimizer. It reports annualized volatility, maximum drawdown, historical constant-weight wealth and stock correlations. This is an in-sample scenario, not an actual portfolio performance record or forecast. Cash earns zero in the calculation. No fabricated fundamentals or benchmark data. All QA examples visibly fictional. Existing feature flags and private transport remain unchanged. Production release requires actual approved research, risk history, validation of data rights, full CI and supervised Telegram delivery.

Large approved history: configure MSK_BUILDER_V2_APPROVED_RESEARCH_FILE with an absolute operator-controlled local path and MSK_BUILDER_V2_APPROVED_RESEARCH_SHA256 with the exact lowercase SHA-256 of the UTF-8 file. Remove the inline research environment variable when using file mode. A digest mismatch, file read error, over-512KB payload, or conflicting sources withhold selection. This is an integrity check, not proof of financial evidence; staging data cannot be published by this loader. No production values were configured.
